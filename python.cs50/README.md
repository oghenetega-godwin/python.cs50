# Object Oriented Programming (OOP) in Python
* A Tuple is an immutable built-in data structure used to store a collection of values or items in a single variable. 
A Tuple is used when you don't want your data to be changed. This helps to avoid errors unlike List which is mutable. 
A Tuple uses () parenthesis as its mode of identification.

* A List is a mutable built-in data structure used to store a collection of values or items in a single variable. Unlike the Tuple, a List is mutable. 
A List uses [] square brackets as its mode of identification.

* A Dictionary is a built in data structure used to store information in keys:value pairs. This structure is a higher advancement of Tuples and List. 
The dictionary uses {} curly braces as its mode of identification. 

* A Class like all object programming languages but particularly in python is used to provide a means of bundling data and functionality together [python documentation]. It is also a blueprint for creating objects.
